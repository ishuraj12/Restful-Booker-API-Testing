# Restful Booker API Testing

## Project Overview

This project covers manual API testing of the Restful Booker API using Postman.

## Tools Used

- Postman
- REST API
- JSON
- GitHub

## APIs Tested

- Generate Token
- Create Booking
- Get Booking
- Update Booking
- Partial Update Booking
- Delete Booking

## Testing Types

- Positive Testing
- Negative Testing
- Functional Testing
- Status Code Validation
- Response Validation
- API Chaining
- Authentication Testing

## Project Objective

The objective of this project is to validate API functionality, request and response data, authentication, status codes, and error handling using Postman.
