# Restful Booker API Testing

## Project Overview

This project covers manual API testing of the Restful Booker API using Postman.

The project includes API request testing, response validation, positive and negative testing, and basic CRUD operations.

## Tools Used

- Postman
- REST API
- JSON
- GitHub

## APIs Tested

- Generate Token
- Create Booking
- Get Booking
- Update Booking
- Partial Update Booking
- Delete Booking

## Testing Types

- Positive Testing
- Negative Testing
- Functional Testing
- Status Code Validation
- Response Validation
- Request/Response Validation

## Postman Collection

The Postman collection contains the API requests used for testing the Restful Booker application.

## How to Run

1. Import the Postman collection into Postman.
2. Set the required environment variables.
3. Run the Generate Token request.
4. Create a booking.
5. Get the booking details.
6. Update or partially update the booking.
7. Delete the booking.
8. Validate the response status codes and response data.

## Key Testing Scenarios

- Verify successful booking creation.
- Verify booking details using Booking ID.
- Verify booking update functionality.
- Verify partial booking update.
- Verify booking deletion.
- Verify invalid requests.
- Verify unauthorized/forbidden requests.
- Validate response status codes and response body.
