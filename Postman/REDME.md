# Postman API Testing

This folder contains the Postman collection and environment files used for Restful Booker API testing.

## APIs Covered

1. Generate Token
2. Create Booking
3. Get Booking
4. Update Booking
5. Partial Update Booking
6. Delete Booking

## Testing

- Positive Testing
- Negative Testing
- Functional Testing
- Status Code Validation
- Response Validation
- API Chaining
- Authentication Testing
